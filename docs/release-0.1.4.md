# Forever Coaching 0.1.4

- Fixed oversized Combat Rogue talent effects that could cover the entire Talents window.
- Fixed oversized static talent borders when VFX is disabled.
- Improved talent matching when the client uses a different rank ID or a talent has no stored spell ID.
- Fixed Combat Rogue's smoke layer not returning after re-enabling VFX.
- Added safeguards to keep static and animated effects attached to talent-sized controls.

Automated checks passed across all nine classes, 27 talent trees and 29 animation themes. Live-client visual confirmation remains separate.

After updating, type `/reload`. If installing for the first time, restart WoW.
