# Preferred recommendation sources

User preference, October 23, 2026: use MythicSim, Wowhead, Mobalytics, Raider.IO,
Forever Logs and similarly established sources for build research.

The current published catalog is limited to the five named source domains.
DamageMeters templates and LepreStore allocations remain archived as research
files but are excluded when generating the addon catalog. The focused view also
checks the source URL before selecting a recommendation. Expanding this source
set should be an explicit editorial change, not an automatic scraper fallback.

- MythicSim: fixed-scenario simulation references, with engine/snapshot context.
- Wowhead: Forever-specific guides; user-submitted guides remain explicitly
  identified as community guides and are not treated as official guide validation.
- Mobalytics: Forever-specific authored guides with matching level/variant.
  The existing Restoration Shaman chart/prose conflict stays excluded from picks.
- Raider.IO: attributed tournament submissions, retaining event, stage, archived
  calculator revision and extra talent-point requirements. The calculator linked
  by Raider.IO is retained for decoding/copying, not promoted as a new guide source.
- Forever Logs: future observed combat comparisons after access is confirmed.
  No log-based proof or live integration is claimed by the current catalog.

One pick per spec/activity and its visible source remain the UI contract. A
source gap stays unavailable; an unsupported allocation is not imported merely
to populate every slot. Existing bundled dates remain their recorded snapshots,
not a claim that all allocations were re-researched today.
