# Build recommendation badges

Every entry in the selected class's catalog is evaluated when class, level or
playstyle changes. Library filters change visibility, not the comparison pool.
The selected build's badge repeats next to its heading, and each library card
shows its own assessment. Suggestions use the same assessments.

- **Best reference:** lowest published board rank among at least two valid,
  eligible references for this class and the selected benchmark activity.
  Equal ranks receive equal badges. This means the bundled fixed raid setup,
  not every possible build or the player's equipment.
- **Top reference:** only one eligible ranked reference exists. No comparison
  between multiple builds is implied.
- **Recommended:** the published guide matches both activity and target level.
  Multiple matching guides can all be recommended; no arbitrary winner is chosen.
- **Proposed fit:** a theorycraft allocation matches the activity and level,
  without measured performance evidence.
- **Duel example:** a submitted level-30 finals allocation in the duel activity.
  Tournament entrants are not ranked by seed, popularity or unverified win rate.
- **Level N**, **Source conflict**, **Overview only**, **Unrated:** an explicit
  reason no performance recommendation is available. Missing data is not a score.

Invalid allocations are excluded from recommendations. All valid catalog entries
remain browsable. Personal stat weights, mana simulations, matchups, tank survival,
AoE and encounter-specific comparisons still require matching evidence; a badge
does not fill those research gaps. Benchmark source:
[MythicSim's fixed reference board](https://mythicsim.com/wow-forever/tier-list),
reviewed October 22, 2026. Existing bundled source snapshots are retained.
