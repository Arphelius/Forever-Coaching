# Live rotation removed

The live rotation engines, icon strip, action-button highlights, swing prompts,
rotation settings and `/fcrotation` command have been removed.

Combat recording, Combat Review, talent inspection, class guides and independent
role warnings remain. No external log uploader or Warcraft Logs import is implemented.

Run `node tests/RunClassCoverageTests.cjs` for simulated shared-feature coverage.
Live-client behavior must be checked separately.
