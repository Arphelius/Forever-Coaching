# Guide browsing

Every dashboard section offers class/spec selection. Scenarios and Learn have menus above Previous/Next, with another menu for jumping directly to a scenario, ability or talent. Gear, Combat Review and Resources use the same selection. Talent Builds retains its class icons and spec buttons and shares the browsing selection with the other pages. Browsing guides does not change real talents or live combat advice; choosing a build in Talent Builds retains its existing activation behavior.

Combat Review filters stored fights by recorded class, specialization and role, including matching fights from other characters. Unknown or mismatched specializations are not guessed. New reviews and exported timelines save the observed class/spec metadata; older reviews can be matched when their actual talent snapshot is sufficient. Opening a post-fight review notification returns to the current character's review. Resources shows the selected build's guide link. The browser also filters imported recordings against the selected class/spec.

Guide text uses separate highlighted headings for conditions, actions, reasons and cautions. Scenarios omit the introductory specialization description and review-basis paragraphs. Learn omits spell IDs, training metadata and repeated source boilerplate. Gear shows the selected build's useful stats and why they matter, followed by the SimGearForever explanation, usage steps and link. General gearing-plan and standalone talent-lesson blocks are omitted. The local browser preview follows the same presentation.

The in-game dashboard keeps one 820 × 540 window on every tab (it still scales down to fit small screens). Talent Builds shows at full size; the reading pages wrap and scroll inside the same shell. See [compact layout](compact-layout-and-reviews.md) for the header, tabs and toolbars. Learn derives its ability list and explanations from the selected allocation's scenario actions, rather than repeating the entire class spellbook across all specs. Gear includes the selected specialization and allocation-specific talent interactions alongside shared stat guidance. Shared stat categories are not artificial per-spec stat weights.

Ability lessons show **What it does / Why it is used / When to use it**. Effects are imported from the saved Forever spellbook, with a rank appropriate to the browsing character's level when available. Missing effect text stays explicitly unknown. Talent lessons show **What it does / Why it is used / Good for this build**. Reviewed talent-rank descriptions take precedence over older bundled effects. Talents absent from the changes-only snapshot retain their pinned description and its original provenance. Build benefits refer to affected spells from the selected allocation's main action checklist, without claiming a measured optimal choice. The browser preview uses the same lesson data and headings.

Combat Review shows up to four finding lines per section by default. **Show details** restores the full findings and recording coverage; **View fight timeline** retains the event evidence. This changes presentation only, not recorded events or the analysis.

The Classic Era/Retail installers include `UI/GuideSelectors.lua` through the main manifest. Restart the client after updating the installed addon to ensure the new load list is read.
