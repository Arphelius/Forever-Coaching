# Professions and crafted consumables

Open **Gear → Professions**, choose a class/spec and select a goal: Leveling,
Dungeons, Raids, PvP or Gold. The reading cards explain the recommended pair,
its use for that build, secondary professions, combat consumables and preparation.
**Gear stats** returns to the existing stats and SimGearForever guide.

Recommendations are qualitative starting points for the selected goal, not measured
profession rankings. Different Druid forms, Shaman roles and Paladin roles have
different equipment/resource needs. The guide does not assume unconfirmed Wrath-style
profession perks. Each page provides copyable Wowhead source links.

Reviewed **2026-11-04** using Wowhead's Forever
[profession overview](https://www.wowhead.com/forever/guide/professions/overview),
[First Aid](https://www.wowhead.com/forever/guide/professions/first-aid/overview),
[Alchemy](https://www.wowhead.com/forever/guide/professions/alchemy-overview-trainer-locations-recipes)
and [Engineering](https://www.wowhead.com/forever/guide/professions/engineering-overview-trainer-locations-recipes).
Standard healing potions are First Aid crafts in Forever. Potions can be bought or
traded; crafting a potion yourself is not required to receive a use suggestion.

## Live suggestions

Crafted-item suggestions start enabled and use the actual character/spec, independently
of the class being browsed. The verified catalog contains 36 consumables:

- First Aid healing potions: below 30% Health.
- Alchemy Mana potions: below 20% Mana, for a character currently using Mana.
- Cooking Thistle Tea: Rogue or Cat Druid, with at least 80 Energy of headroom.
- Rage potions: a permitted class using Rage, below 20 Rage.
- Six ranks each of Frenzy, Spellblasting and Mender's Potions: attack power,
  spell damage or healing power for the detected build, during a requested burst window.
- Iron and Thorium Grenades: only with the required Engineering skill, an attackable
  living target, area damage permitted, and no movement or current cast/channel.

Only bag items count. Every suggestion requires readable positive inventory count,
item usability, a ready cooldown and the verified current item-use spell. Item data
is requested for owned items when needed. Level/class/skill requirements apply;
unknown or restricted fields do not produce guesses. The client's shared potion and
explosive cooldowns are checked per item. No healing, resource or cooldown gain is
assumed in a multi-item forecast: the suggestion contains one item.

Urgent assigned mechanics/interrupts stay ahead of optional items. Emergency recovery
precedes offensive consumables, including manually configured burst items. Manual
items remain scoped to the character's actual allocation. Crafted armor, weapons,
food, enchants and oils are preparation advice rather than combat casts. Self-damaging
sappers and context-dependent bandage/escape effects are not automatically suggested
without the context required to recommend them correctly.

Use **Crafted items: On/Off** on the profession page or in rotation settings, or
`/fcrotation crafted on` and `/fcrotation crafted off`. Offensive potions follow
`/fcrotation burst on`; grenades follow `/fcrotation aoe`. Burst resets after combat.
`/fcrotation item ID off` also excludes that specific item from automatic suggestions.
Explicitly assigning it again clears that exclusion.

The addon displays advice and highlights existing action buttons. It never uses,
crafts or purchases an item, learns a profession, equips gear or chooses a ground
target automatically. The browser preview shows guide content; it does not claim to
read the live game's bags.

## Updating the catalog

`Data/ProfessionItems.lua` and `docs/research/profession-items.json` retain IDs, use
spell IDs, class/level/skill restrictions, effect families and Wowhead source links.
They are generated by `tools/Import-ProfessionItems.cjs <saved-tooltip-directory>`
from saved public Forever tooltip responses. Craft-spell responses identify the
created item; recipe item IDs are never used as consumable IDs. New item families
require explicit classification and tests. Verify changed effects/requirements
against current Wowhead item pages and the actual game before publishing.

Validation: `tests/ProfessionItems.Tests.cjs`, native profession-mode checks in
`tests/ReadingPages.Tests.cjs`, and all-class browser coverage in
`tests/ForeverSpellPreview.Tests.cjs`. Actual client rendering and item usability
still require an in-game test.
